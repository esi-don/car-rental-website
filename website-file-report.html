Esrom Ridez Website File Report

Overview

This website is a static car-rental landing site for Esrom Ridez, designed for users to browse vehicles, compare options, choose pickup/return dates, request a booking, and contact the business. The site uses plain HTML, CSS, and JavaScript with no backend framework or database. It is a front-end website that stores car and booking data locally in the browser and submits forms to Formspree for email delivery.

The project is a small brochure-style site with multiple pages, a fleet browser, a booking modal, and a staff/admin workspace used for managing vehicle pricing and booking statuses.

Important Files and What They Do

  • index.html — This is the homepage. It contains the main hero section, landing message, navigation, search form for pickup date and location, overview links, and the staff workspace section. It also includes the booking modal and toast notification container used by the JavaScript.
  • cars.html — This page is the car catalog. It displays the search form for location and dates, filters for vehicle type/seats/price, and a dynamic vehicle grid populated by JavaScript. Users can click a car to open a booking form and estimate the cost.
  • how-it-works.html — This page explains the booking process step by step, from sending a request to receiving confirmation. It helps customers understand how the rental process works before they book.
  • helpful-answers.html — This is the FAQ page. It contains common customer questions about drivers, luggage, payments, pickup points, and booking confirmations. It gives users practical answers to reduce uncertainty before contact.
  • contact.html — This page provides contact information and a message form for customers who want to ask about routes, booking requests, luggage, or available cars. It connects to Formspree so the details are sent by email.
  • site.css — This is the main stylesheet for the entire website. It controls typography, layout, colors, navigation bars, cards, modal windows, forms, responsiveness, and every design element on the site. It is responsible for the overall look and feel.
  • script.js — This is the main logic file for the site. It contains the fleet data, price calculations, booking logic, form submission, modal behavior, filtering, booking confirmation, and the admin panel logic. It also manages local storage for saved vehicles and bookings.
  • README.md — This is the repository description file. At present it is minimal and only contains the project title, but it is the standard place to add setup notes, usage instructions, or project information in the future.

What the JavaScript File Controls

The script.js file is the heart of the website. It does the following:

  • Defines the list of vehicles, including name, type, seating capacity, luggage, transmission, driver requirement, and pricing.
  • Renders the fleet cards and filters them by type, seating capacity, and price.
  • Calculates rental totals including daily rate, driver cost, child seat, and one-way trip difference.
  • Displays a booking modal with a form used for customer booking requests.
  • Validates pickup and return dates to ensure logical entries.
  • Submits new booking requests and contact forms to Formspree.
  • Loads and saves data in browser local storage so the page can remember pricing and bookings locally.
  • Provides an admin view for staff to view bookings, change vehicle pricing, and toggle availability.
  • Shows toast notifications for user feedback such as errors or successful request submission.

Image and Media Files

The site includes several image files used as car photos and one landscape photo for the homepage hero section.

  • kla road.png — The hero background image on the home page, representing the travel experience and road journey.
  • car 1.png through car 25.png — Vehicle photos used in the fleet and modal gallery for the cars available for rent.

These image files are important for the visual presentation and for helping users see the cars before booking.

Website Structure Summary

The project is structured as a simple multi-page static website:

  • Home page introduces the business and gives a starting point for booking.
  • Cars page allows customers to browse and select cars.
  • How it works page explains the rental process.
  • Helpful answers page addresses common questions.
  • Contact page is used to reach the business directly.
  • Common styling and interaction logic are shared across all pages via CSS and JavaScript.

Final Assessment

Overall, this is a front-end rental website for car browsing and booking. The main purpose of each file is to support the user experience: create a professional visual design, explain the service, let users browse available cars, and submit requests for booking or contact. The combination of HTML pages, CSS styling, and JavaScript interaction makes the website easy to use and visually consistent.
